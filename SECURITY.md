# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.3.x  | ✅ Active          |
| v0.2.x  | ⚠️ Critical fixes only |
| < 0.2   | ❌ No              |

## Reporting a Vulnerability

ShieldScan handles sensitive security data — we take reports seriously.

**Do not open a public GitHub issue for security bugs.**

### How to report

1. **Email:** security@shieldscan.dev
2. **Alternative:** Open a [GitHub Security Advisory](https://github.com/poxsky/antivirus/security/advisories/new) (private)

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
- Your contact for follow-up

### What to expect

- **Acknowledgement:** within 48 hours
- **Triage & assessment:** within 5 business days
- **Fix timeline:** depends on severity — Critical issues are prioritized for a patch release
- **Disclosure:** We follow coordinated disclosure. We'll agree on a public disclosure date after a fix is available.

### Scope

- ShieldScan app itself (scanner bypass, data leak, permission misuse, etc.)
- Build / supply-chain issues in this repo

Out of scope: Social engineering, physical device access, Android OS zero-days that ShieldScan cannot mitigate.

### Safe Harbor

We will not pursue legal action against researchers who follow responsible disclosure and avoid privacy violations, data destruction, or service disruption.

Thank you for helping keep ShieldScan and its users safe.
